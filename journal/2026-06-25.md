# Founder Journal: 25 June 2026

## Focus

Start making FamilyOS real by moving the Product Bible and working documentation into GitHub.

## Key decisions

### GitHub becomes the source of truth

The repository will hold the permanent memory of the project. Important product decisions, standards, build packs, prompts and architecture notes should be committed rather than left only in chat.

### FamilyOS is positioned as life at home software

The product should not only serve traditional families. It should support households, couples, co-parents, carers, flatmates, blended families, pet owners and multi-generational care.

### Build Packs replace normal PRDs

Each major product area will receive a full Product Build Pack, not just a feature PRD. A Build Pack should support product, design, engineering, AI and QA.

### Today is the first Build Pack

Today is the flagship surface. It should prepare people for the day and create the daily habit loop.

### Living Scenarios come first

Each Build Pack should start with a real-life story before requirements. The first Living Scenario is Monday Morning.
