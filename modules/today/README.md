# Build Pack 001: Today

## Status

Draft v0.1

## Product area

Core Platform

## Surface name

Today

## Purpose

Today is the flagship daily surface for FamilyOS. It prepares the household for the day ahead by bringing together time, responsibilities, money, care, reminders, weather, travel, commitments and AI guidance into one calm view.

Today is not a dashboard. It is a daily briefing.

## Core promise

Open FamilyOS. Understand the day. Feel prepared.

## Primary outcome

The user should be able to open Today for under 30 seconds and leave feeling calmer, more organised and more confident.

Today succeeds when users instinctively open FamilyOS every morning because they trust it to tell them what matters.
