# Mental Load Framework

FamilyOS is built around one central problem: the invisible mental load of everyday life.

## Definition

Mental load is the gap between everything a person must remember and everything their brain can comfortably hold.

FamilyOS exists to close that gap.

## The Five Layers of Mental Load

### 1. Remember

Users worry about forgetting bills, appointments, birthdays, forms, medication, school events, and household admin.

FamilyOS should remember these things for them.

### 2. Coordinate

Households involve multiple people, responsibilities, permissions, calendars, and expectations.

FamilyOS should make ownership and coordination visible.

### 3. Decide

People face decision fatigue every day.

FamilyOS should offer sensible defaults, useful suggestions, and fewer choices when possible.

### 4. Prepare

Many stressful moments are caused by poor preparation.

FamilyOS should prepare ahead of time through reminders, packing lists, document prompts, travel guidance, and financial planning.

### 5. Reflect

People often fail to notice progress.

FamilyOS should help households see wins, memories, savings, completed projects, and improved preparedness.

## Mental Load Loop

Most life admin follows this negative loop:

Remember → Forget → Stress → Recover → Repeat

FamilyOS should replace it with:

Capture → Organise → Predict → Support → Reflect

## Design Implication

Every feature must answer:

- Does this reduce remembering?
- Does this reduce coordination?
- Does this reduce decision fatigue?
- Does this improve preparedness?
- Does this increase confidence?
