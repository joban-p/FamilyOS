# Accessibility Standards

Accessibility is a core product principle for FamilyOS.

## Minimum Standard

FamilyOS should meet WCAG 2.2 AA as a minimum.

The product should aim for AAA where practical, especially for readability, contrast, touch targets, and error prevention.

## Requirements

- Support screen readers.
- Support keyboard navigation where relevant.
- Support switch control.
- Support voice interaction.
- Support Dynamic Type and large text.
- Respect reduced motion preferences.
- Provide high contrast modes.
- Avoid relying on colour alone.
- Use minimum 44 by 44 point touch targets.
- Write in plain English.
- Provide accessible alternatives for gestures.

## Design Principle

Accessibility is not a compliance task.

It is how FamilyOS becomes easier for everyone to use.
