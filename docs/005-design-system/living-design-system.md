# Living Design System

FamilyOS should feel like a premium lifestyle product, not an admin tool.

## Visual Principles

- Calm before clever
- Function before decoration
- Whitespace before density
- Typography before colour
- Content before interface
- Confidence before engagement
- Accessibility before aesthetics
- Consistency before novelty

## Visual Personality

FamilyOS should feel:

- Warm
- Premium
- Natural
- Quiet
- Trustworthy
- Modern
- Human
- Timeless

## Interface Direction

The interface should feel like a beautifully organised home.

Cards should feel soft and useful.

Typography should guide attention.

Colour should communicate meaning.

Motion should explain change.

Whitespace should reduce cognitive effort.
