# Relationship Engine

The Relationship Engine is the conceptual core of FamilyOS.

Most apps store information in separate feature silos. FamilyOS connects information into a private household graph.

## Household Graph

A household graph connects:

- People
- Places
- Things
- Events
- Commitments
- Tasks
- Money
- Documents
- Memories
- Goals
- Pets
- Projects

## Example

A school trip may connect:

- Child
- Parent
- School
- Teacher
- Calendar event
- Permission slip
- Packing list
- Travel plan
- Spending money
- Reminder
- Photos
- Memory

## AI Benefit

AI becomes more useful because it understands context.

Instead of asking the user for everything, it can infer relationships from the household graph, then ask only when confidence is low.

## Product Benefit

The Relationship Engine makes FamilyOS feel like one connected operating system instead of a set of disconnected tools.
