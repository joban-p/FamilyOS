# Success Metrics

FamilyOS measures success by reduced mental load, not screen time.

## Primary Metrics

- Weekly active households
- Time saved per household
- Tasks captured in under five seconds
- AI suggestions accepted
- Reminders prevented through proactive planning
- Household confidence score
- Monthly retention
- Net Promoter Score

## Product Health Metrics

- Time to first value
- Time to first capture
- Time to complete common tasks
- Percentage of users using shared household features
- Percentage of households with two or more active members
- Percentage of captured items successfully classified by AI
- Number of unresolved inbox items

## Emotional Outcome Metrics

The product should make users feel:

- More prepared
- Less overwhelmed
- More confident
- More connected
- More in control

## Metrics We Do Not Optimise For

- Screen time
- Notification volume
- Artificial streaks
- Addictive engagement loops
- Feature usage without real value
