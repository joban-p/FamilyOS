It explains why the product exists, how it should behave, how it should be designed, how it should be built, and how every module should evolve.

## Product Build Packs

Each module will receive a full Product Build Pack, not just a PRD.

A Product Build Pack includes:

- Executive summary
- Vision
- User problem
- Jobs To Be Done
- Mental load analysis
- User journeys
- UX specification
- UI specification
- Interaction specification
- Motion specification
- Accessibility specification
- AI behaviour
- Technical architecture
- Data model
- API contracts
- Permissions
- Offline behaviour
- Sync strategy
- Security and privacy
- Analytics
- Notifications
- Edge cases
- Acceptance criteria
- QA test plan
- Figma specification
- Engineering specification
- AI coding prompt
- Future roadmap

## First Build Pack

The first full build pack will be the Today module.

Today is the daily surface that helps users understand what matters now, what needs action, and what can wait.
