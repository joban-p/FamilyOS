# The No List

FamilyOS will never intentionally:

- Shame users for missed habits, late tasks, or imperfect routines.
- Optimise for screen time over quality of life.
- Use dark patterns.
- Sell private family data.
- Hide how AI uses household information.
- Make irreversible decisions without explicit consent.
- Send unnecessary notifications.
- Force complex setup before value is delivered.
- Treat one family structure as the default.
- Require internet access for core daily workflows where offline support is practical.
- Use gamification that creates guilt, pressure, or dependency.
- Prioritise novelty over real-world usefulness.
- Allow automation to reduce user control.
- Make accessibility a later-stage task.

If a proposal conflicts with this list, it should be redesigned or removed.
