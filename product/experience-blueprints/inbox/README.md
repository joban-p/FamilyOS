# Experience Blueprint 002: Universal Capture Engine

## Working user-facing name

Inbox

## Status

Draft v0.1

## Purpose

The Universal Capture Engine is the front door to FamilyOS.

It allows users to capture anything in under five seconds and trust FamilyOS to organise it afterwards.

## Core promise

Capture anything. FamilyOS works out where it belongs.

## Core principle

Capture first. Organise later.
