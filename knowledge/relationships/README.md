# Relationships

Relationships define how FamilyOS understands household context.

The product should avoid isolated records wherever possible. Each object should connect to the people, places, events, documents, money and responsibilities that make it meaningful.

## Core relationship examples

- Person belongs to Household.
- Pet belongs to Household.
- Event involves Person.
- Document relates to Asset.
- Receipt creates Expense.
- Expense affects Budget.
- Task prepares Event.
- Reminder relates to Task.
- Goal belongs to Household.

## Principle

Relationships make AI useful. Without relationships, FamilyOS is only storage. With relationships, it becomes household intelligence.
