# FamilyOS Knowledge Platform

The Knowledge Platform defines the concepts, entities, relationships, taxonomies, confidence models and automation rules that power FamilyOS.

FamilyOS is relationship-first software. It does not only store objects. It understands how household information connects.

## Sections

- `entities` defines core objects such as Household, Person, Event, Task and Document.
- `relationships` defines how entities connect.
- `taxonomy` defines shared categories and naming.
- `automation-rules` defines how captured inputs create outcomes.
- `confidence-models` defines thresholds for AI action, suggestion and review.

## Principle

One input should create many meaningful outcomes when confidence and permissions allow it.
