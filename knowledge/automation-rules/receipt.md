# Automation Rule: Receipt Capture

## Input

Receipt captured by camera, image upload, screenshot or shared file.

## Possible outputs

- Expense created.
- Merchant detected.
- Amount extracted.
- Date extracted.
- Budget updated.
- Category suggested.
- Warranty detected if relevant.
- Asset linked if relevant.
- Original receipt archived.

## Confidence behaviour

High confidence actions may be automated.

Lower confidence categorisation should be suggested for user confirmation.

## User experience principle

The user should only need to capture the receipt. FamilyOS should do the organisation.
