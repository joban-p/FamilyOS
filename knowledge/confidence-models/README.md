# Confidence Models

Confidence models define when FamilyOS should automate, suggest, ask or do nothing.

## Default thresholds

### 95 to 100 percent

Automate when permission exists and the action is reversible or low risk.

### 80 to 94 percent

Suggest with one-tap confirmation.

### Below 80 percent

Place in Inbox Review or ask a clear clarifying question.

### Below 60 percent

Do not act automatically. Preserve the capture and wait for user review.

## Principles

- Never pretend to know.
- Explain important actions.
- Make automation reversible where possible.
- Learn from corrections.
- Use stricter thresholds for sensitive data.
